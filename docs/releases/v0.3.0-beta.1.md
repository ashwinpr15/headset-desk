# Headset Desk 0.3.0 Beta — Windows application

An installable Windows app for **WH-1000XM5** and **WH-CH720N**, with a window and system tray.

Windows 11 x64. The installer includes required runtime files, installs for your account without administrator rights, creates a Start menu shortcut, and includes an uninstaller. Alternatively, extract the entire portable ZIP and open `headset-desk.exe`. No Qt installation, developer tools, account or internet connection is needed to run the app. The app and installer are unsigned; Windows SmartScreen may show an unrecognized-app warning.

## Features

- Battery percentage, charging state, firmware, model and headset-reported codec.
- NC, Ambient 1–20 and Off.
- Five-band graphic EQ and Clear Bass (−10..+10), with explicit Apply and local Reset.
- Light/dark appearance, resizable window and native tray. Close hides to tray; Quit exits.
- Auto-connect when a supported paired headset is active, manual Connect otherwise. One session at a time.
- Single-instance forwarding, manual refresh, refresh on reopening and a slow battery timer.
- No firmware updates, power commands, sign-in startup, cloud, analytics or internet updater.

## Experimental controls and evidence

Controls are **off by default**. Turn on **Controls** in the Noise control card to opt in for the current connection. Disconnecting, changing headsets, reconnecting or a failed change disables them.

Noise and EQ writes remain **not physically verified on either model**. Existing physical captures cover returned reads on XM5 firmware 2.5.1 and CH720N 1.1.4, in Off mode, not charging, and one EQ state. Successful reads do not prove setting writes. Unknown hardware write confidence remains separate from experimental opt-in.

Each setting is validated, sent once, waits for an ACK, and is checked by a fresh readback. ACK alone is not success. A mismatch, timeout or disconnect reports a problem and disables controls. No setting retry, rollback or reconnect replay. Check Sony's app when testing changes. The two models' captured noise replies differ; this release makes no broad hardware compatibility claim.

Model name comes from Windows' pairing cache. The reported codec is not a Windows audio-codec measurement. Charging true, other firmware, additional noise/EQ states, real GUI/reconnect and long-session operation still require physical testing.

## Validation and size

- 7/7 offline test groups: 105 C++ cases and six desktop scenarios; desktop scenarios exercised at 100% and 150% scaling.
- Offline noise/EQ boundaries, exact frames, ACK loss, disconnects, mismatches, invalid requests and no-write-replay checks.
- Installed app launch, file-hash comparison, running-app installer protection and uninstall passed in a disposable test directory.
- Portable app launched with only its bundled Qt runtime, and a second launch forwarded to the first.
- Deployed folder: 67.89 MiB. Six local warm simulated launches: median 1.01 seconds to first frame; visible idle working set 183.6–192.9 MiB. These are local measurements, not hardware connection or cold-start claims.
