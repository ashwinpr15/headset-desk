# Headset Desk v0.1.1-diagnostics.1

Experimental Windows 11 x64 diagnostic prerelease. This release packages the working protocol/core and internal read-only CLI. The desktop window, tray lifecycle, editable NC/Ambient/EQ controls and installer are planned for later phases.

## Included

- Portable `headset-desk-diagnostics.exe`, with no Qt installation required.
- Supported paired-device listing and explicit read-only diagnostics for WH-1000XM5 and WH-CH720N.
- Battery, charging, firmware, headset-reported codec, noise state and five-band EQ/Clear Bass reads.
- V2 service selection and a final guard blocking every setting write.
- Reviewed physical captures from XM5 2.5.1 and CH720N 1.1.4, preserved as offline regression fixtures in the repository.
- MIT source attribution and runtime license notices.

## Validation

Six local CTest groups passed: 100 C++ test cases / 881 assertions, both CLI simulations and refusal checks. Both real headset captures answered all six queries, contained only allowlisted GETs and ACKs, and matched the user's reported values. Portable smoke checks use only Windows System32 on PATH. GitHub's Windows workflow builds and runs offline checks; current results are visible in Actions.

## Limits

Noise control was observed only in Off mode and charging only as false. EQ evidence covers each captured state, not every preset or range endpoint. AAC is the headset-reported value, not independent proof of Windows' negotiated codec. The paired Windows name supplies model identity. CH720N write confidence remains UNKNOWN, and all writes stay disabled on both models. This unsigned development tool is not the finished desktop app.

## Use

Extract the Windows x64 ZIP, open PowerShell in that folder, and run:

```powershell
.\headset-desk-diagnostics.exe --devices
.\headset-desk-diagnostics.exe --device-index N --read-only --dump capture.txt
```

Replace `N` with the desired headset's displayed number. Pair through Windows Bluetooth settings first. Use a fresh capture filename. Without arguments the tool displays help and opens no connection. `--simulate xm5` and `--simulate ch720n` produce clearly labeled synthetic data.
