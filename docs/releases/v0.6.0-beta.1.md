# Headset Desk 0.6.0 Beta — follows your headphone buttons

Press the NC/Ambient button on your headphones and Headset Desk now follows along. This release also smooths out a few everyday moments.

Windows 11 x64. Installs for your account without administrator rights. Installing over an earlier version upgrades it in place; quit the old version from the tray first. The app and installer are unsigned, so Windows SmartScreen may warn about an unrecognized app.

## New

- **Headphone buttons stay in sync.** When you switch noise mode on the headset, the tiles, the drawing and the tray update, and a small toast says what changed ("Ambient, changed on your headphones"). The app uses the headset's own notification, and while the window is open it also re-reads the mode every few seconds as a fallback. Neither sends a setting. Only receiving is involved.
- **Tap a mode, even when changes are locked.** Instead of greyed-out tiles, the app asks: *Switching to Ambient needs Allow changes.* **Turn on and switch** does both in one step; **Not now** leaves everything as it was.
- **Current mode at a glance** in the device card (for example "Ambient · level 12").
- **Quick switch from the tray:** the tray menu lists Noise Cancelling, Ambient and Off. These work while Allow changes is on, and the menu says so when it isn't.
- **Keyboard shortcuts:** Ctrl+1 to Ctrl+4 for the pages, F5 to refresh.

## Unchanged

Everything that worked in 0.5.0 behaves the same: the CH720N mode fix, read-back confirmation for every change (sent once, never resent), Allow changes resetting on disconnect, Speak-to-Chat and DSEE as experimental opt-ins, the tray and single-instance behaviour.

## Evidence

Button detection uses the notification layout of the reply the app already reads (`69 17`, like `67 17`). It hasn't been captured on the owner's headsets yet. If the toast doesn't appear when you press the button, the mode still updates within about 4 seconds while the window is open. Please report either way.

## How this build was made

Built and checked by the [desktop workflow](https://github.com/ashwinpr15/headset-desk/actions/workflows/desktop-release.yml) on GitHub's Windows runners with Qt 6.8.3 (mingw_64) and MinGW GCC 13.1.0. The run covered offline protocol, control and QML tests, including a simulated headset button press. It also captured simulated screenshots with only the bundled runtime on PATH, then installed, hash-checked, launched and uninstalled the installer silently. No commands were sent to physical headphones during development.
